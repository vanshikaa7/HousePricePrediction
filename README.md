# HousePricePrediction

## Project Overview
This project aims to develop an intelligent machine learning model to predict house prices based on various features such as area, location, and amenities. Using a dataset of over 2,000 records, the model achieves approximately 87% accuracy, helping buyers, sellers, and real estate professionals make data-driven pricing decisions.

## Objective
The primary goal of this project is to create a reliable house price prediction system that minimizes subjectivity in property valuation by leveraging machine learning techniques.

## Technologies & Tools Used
- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook
- **Libraries Used:**
  - **Data Processing:** Pandas, NumPy
  - **Data Visualization:** Matplotlib, Seaborn
  - **Machine Learning:** Scikit-Learn

## Methodology
1. **Data Pre-processing:**
   - Handled missing values and cleaned the dataset using Pandas and NumPy.
   - Normalized numerical features for better model performance.
2. **Exploratory Data Analysis (EDA):**
   - Created insightful visualizations to understand trends and relationships among key property features.
   - Analyzed the impact of factors such as area, location, and amenities on house prices.
3. **Feature Engineering:**
   - Selected the most relevant features to improve model accuracy.
4. **Model Implementation:**
   - Applied regression techniques using Scikit-Learn.
   - Implemented train-test splitting for better generalization.
5. **Model Evaluation:**
   - Assessed performance using Mean Squared Error (MSE) and R-squared metrics.
   - Optimized hyperparameters to enhance accuracy.
